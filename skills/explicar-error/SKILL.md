# Explicar un error

1. Si el usuario no pegó el error, usa ver_pantalla para leerlo.
2. Encuentra la línea que importa (la primera del error o la que menciona un archivo del proyecto).
3. Explica en una frase qué significa, sin jerga.
4. Si menciona un archivo del proyecto, ábrelo con leer_archivo y mira esa línea.
5. Da el arreglo más probable con el código exacto. Si hay dos causas posibles, di cómo distinguirlas.
6. Si el error es de una versión o paquete que no conoces, busca el mensaje exacto con buscar_web.
